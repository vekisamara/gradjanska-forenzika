# Arhiva za naknadnu validaciju

Ovdje se čuvaju povučene verzije i prototipovi koji nisu aktuelna metodološka ili tehnička preporuka. Nisu izbrisani kako bi ostala sljedivost razvoja.

| Materijal | Razlog arhiviranja |
|---|---|
| metodologija v2.0 | zamijenjena novijim standardom i operativnim paketom |
| stari DOCX anonimizator i uputstvo | zahtijeva novu provjeru privatnosti, formata i pokrivenosti |
| staro uputstvo za PDF metapodatke | sadržalo je prejak zaključak iz metapodatkovnog signala |
| nekalibrisani skener rizika | fiksne fraze i bodovi nisu validirani kao indikator |
| rani prompt revizora narativa | prototip izvan aktuelne kontrolisane biblioteke |

Povratak materijala u aktivni dio zahtijeva vlasnika, novu verziju, dokumentovana ograničenja, odgovarajuće testove i ažurirane veze.
