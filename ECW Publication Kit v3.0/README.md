# ECW Publication Kit v3.0

Standardizovani izdavački sistem za seriju **EU Compliance Watch** projekta Civic Forensics.

## Serije

- `ECW-DD-xxx` — Deep Dive
- `ECW-WR-xxx` — Watch Report
- `ECW-CG-xxx` — Citizen Guide
- `ECW-CL-xxx` — Citizen Checklist

## Sadržaj paketa

- `visual-identity/` — vizuelni identitet, paleta i osnovna oznaka serije
- `editorial/` — uređivački i citatni standard
- `templates/` — strukture za četiri vrste publikacija
- `styles/` — digitalni stilovi za portal i HTML izvoz
- `metadata/` — mašinski čitljiva šema publikacije
- `image-prompts/` — standardizovani promptovi za naslovne ilustracije

## Temeljni princip

Publikacija mora omogućiti čitaocu da razlikuje:

1. provjerenu činjenicu;
2. pravno ili regulatorno pravilo;
3. analitički zaključak;
4. otvoreno pitanje;
5. preporučenu radnju;
6. dokaz koji nedostaje.

## Izdavački tok

`Research dossier → Civic Forensics analysis → Publication → Companion package → Version update`

## Minimalni metapodaci

Svaka publikacija sadrži: seriju, broj dokumenta, naslov, verziju, datum, status, jezik, izdavača, preporučeni citat, kategoriju, ključne riječi i istoriju verzija.
