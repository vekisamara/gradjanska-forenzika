# NIR Strategy Review v0.3

## Svrha

Revizija strategije nakon Institutional Response Simulatora. Simulirani odgovori nisu dokaz i koriste se samo za otkrivanje ranjivosti.

## Koraci

### 1. Validate assumptions
Za svaku važnu pretpostavku: CONFIRMED BY EVIDENCE / REASONABLE INFERENCE / UNTESTED / WEAK / CONTRADICTED.

### 2. BATNA review
Provjeri dostupnost, trošak, trajanje, zavisnost od drugog organa i izvršivost. Ocjena: STRONG / MODERATE / WEAK / UNKNOWN.

### 3. Leverage review
Za D/L/P/I/R/A kategorije označi: ACTUAL / POTENTIAL / SPECULATIVE i navedi O/K/R/N izvorni status.

### 4. Counterargument review
Za svaki jak simulirani argument:
- OUR ANSWER
- EVIDENCE
- CONFIDENCE
- REMAINING VULNERABILITY

### 5. Concession review
Klasifikuj: LOW COST/HIGH VALUE / BALANCED / HIGH COST/LOW VALUE / DANGEROUS / UNNECESSARY. Ne preporučuj ustupak koji slabi rok, pravo ili dokaznu poziciju.

### 6. Failure conditions
Strategiju ne nastavljati neizmijenjenu ako se pojavi nova kontradikcija, BATNA nije dostupna, postoji Prioritet A, teče kritični rok, formalni procesni okidač je nastao ili pregovor proizvodi samo prepisku.

### 7. Revised strategy
Izlaz:
- PRIMARY STRATEGY
- SECONDARY STRATEGY
- BATNA
- BEST FIRST MOVE
- FIRST QUESTION
- FIRST DOCUMENT TO PRESENT
- INFORMATION TO RESERVE
- POSSIBLE TRADE
- NON-NEGOTIABLE ISSUE
- MDAP HANDOFF TRIGGER

### 8. Response tree
Jedan naredni potez za: accept / partial accept / request more info / refuse / lack of jurisdiction / deadline pressure / compromise / silence.

### 9. Readiness
Ocijeni evidence readiness, procedural readiness, BATNA strength, communication readiness, cognitive bias risk i unnecessary escalation risk.

Finalno: READY / READY WITH CONDITIONS / NOT READY, uz najviše tri radnje prije kontakta.

Ako je potreban formalni pravni lijek ili stepen eskalacije, označi `HANDOFF TO MDAP` umjesto samostalnog izbora instrumenta.
