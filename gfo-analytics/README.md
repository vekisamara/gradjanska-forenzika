# GFO Analytics

GFO Analytics je zajednički podatkovni i analitički sloj projekta Građanska forenzika.

Ovaj direktorij sadrži kanonske standarde, radne verzije, sheme i buduće analitičke module. Standardi definišu podatke i interoperabilnost; posebni moduli definišu analitičku logiku.

## Trenutni moduli

- `election-data-standard/` — prvi kanonski podatkovni standard za izbornu analitiku.

## Osnovno pravilo

`RAW -> NORMALIZED -> DERIVED -> INTERPRETED`

Podatak mora ostati razlikovan od izračuna, a izračun od interpretacije.

## Status

Rad u razvoju. Sve radne verzije se čuvaju u repozitoriju radi auditabilnosti i istorije razvoja.
