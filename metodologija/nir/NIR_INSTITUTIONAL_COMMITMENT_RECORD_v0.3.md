# NIR Institutional Commitment Record v0.3

Koristi se samo za stvarnu komunikaciju. Simulirane izjave se ne upisuju kao ICR.

```text
ICR-ID:
CASE ID:
DATE:
ACTOR:
INSTITUTION:
CHANNEL: email / dopis / zapisnik / sastanak / drugo

COMMITMENT:

EXPECTED ACTION:

DEADLINE:

SOURCE:
SOURCE STATUS: O / K / R / N

FULFILLED: YES / NO / PARTIAL / UNKNOWN
FULFILMENT EVIDENCE:

RESULTING NEW FACT:

RESULTING NEGATIVE EVIDENCE:

MDAP REASSESSMENT REQUIRED: YES / NO
MDAP TRIGGER IF UNFULFILLED:

NOTES:
```

Pravila:
1. Obećanje bez provjerljivog izvora označiti R ili N.
2. Propušteno obećanje nije automatski dokaz namjere.
3. Neispunjen ICR vraća se MDAP-u radi procjene dokaznog i procesnog značaja.
4. Rok iz ICR-a ne zamjenjuje zakonski rok.
