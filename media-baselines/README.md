# GFO MEDIA — Baseline Archive

This directory stores structured longitudinal baseline records created under `metodologija/media-analysis/17_baseline_pattern_memory_layer_v1_0.md`.

## Important

This archive starts prospectively and empty of historical case conclusions.

Existing analyses and posts elsewhere in the repository are **not automatically converted into baseline evidence**. Historical material may be migrated only through a separate evidence-recheck process that reconstructs the baseline from the underlying sources rather than copying prior AI conclusions.

## Naming convention

`YYYY-MM-DD__GFO-MEDIA-<ID>__short-neutral-slug.md`

Use neutral factual slugs. Do not encode allegations, guilt, corruption or intent in filenames.

## Baseline creation rule

A record is created for:

- a completed analysis designated for publication;
- a published GFO Media post;
- an unpublished analysis explicitly marked `SIGNIFICANT`.

Low-signal, duplicate and abandoned analyses should not enter the archive.

## Core rule

A baseline is a retrieval and evidence-memory object, not an authority. A previous GFO conclusion is never proof of recurrence. Any prior event counted toward a recurring pattern must be tied back to rechecked underlying evidence.

## Workflow

`PRIMARY ANALYSIS → BASELINE SEARCH → PATTERN COMPARISON → EVIDENCE RECHECK → PATTERN ASSESSMENT → PUBLICATION → BASELINE CREATE/UPDATE`

The baseline search must not precede the independent primary analysis pass.

## Pattern levels

`P0` no prior pattern  
`P1` thematic similarity  
`P2` repeated indicator  
`P3` documented recurring pattern  
`P4` systemic pattern candidate  
`P5` systemic pattern supported

See the methodology layer for thresholds and safeguards.
