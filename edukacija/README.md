# Edukacija

Ovaj direktorij okuplja materijale za razvoj demokratske, medijske, podatkovne, administrativne i AI pismenosti.

Trenutno je dostupan [`glosar.md`](glosar.md). Budući moduli treba da navedu ciljnu grupu, ishode učenja, preduslove, trajanje, vježbu, kriterijum provjere i pravila zaštite učesnika. Planirani sadržaj označava se kao nacrt dok ne prođe pilot i evaluaciju.


## Plan modula

| Modul | Programska veza | Status |
|---|---|---|
| Činjenica, tvrdnja i dokaz | demokratska i građanska pismenost | planirano |
| Izvori, kontekst i institucionalni PR | medijska i informaciona pismenost | planirano |
| Brojevi, indikatori i kvantitativni formalizam | podatkovna pismenost | planirano |
| Akti, nadležnosti, rokovi i FOI | pravna i administrativna pismenost | planirano |
| Sigurna i provjerljiva upotreba AI-a | odgovorna AI pismenost | planirano |
| Od nalaza do proporcionalnog djelovanja | građansko djelovanje | planirano |

Statusi materijala su: **planirano**, **nacrt**, **spremno za pilot**, **pilotirano**, **revidirano** i **objavljeno**. Pilotirani modul mora navesti ciljnu grupu, broj učesnika, način evaluacije, ograničenja i promjene nastale poslije povratnih informacija.
