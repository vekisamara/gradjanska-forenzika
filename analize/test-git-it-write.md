# Test Git it Write objave

Ovo je test objava iz GitHub repozitorija.

Ako se ovaj tekst pojavi u WordPress adminu pod **Posts → All Posts**, Git it Write ispravno povlači Markdown fajlove iz foldera `analize/`.

Ako se ne pojavi, problem je vjerovatno u putanji foldera, GitHub autorizaciji ili načinu na koji plugin čita Markdown fajlove.
